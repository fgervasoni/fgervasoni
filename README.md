### `01 / SELECT PROJECT`

**[Pixel Rush](https://pixel-rush.it)** è il mio laboratorio arcade: un gioco
pixel art per **web, Android e iOS**, costruito in JavaScript senza framework.
Bersagli, bombe, bonus e powerup: riflessi veloci, un pixel alla volta.

|   🎯 Partita rapida   |   📅 Missione del giorno    |   ⚔️ Duello 1 vs 1   |        👾 Storia        |
| :-------------------: | :-------------------------: | :------------------: | :---------------------: |
| Insegui il tuo record | Una nuova sfida ogni giorno | Invita un avversario | Affronta livelli e boss |

Il gioco funziona anche offline nelle modalità supportate. Per le partite rapide
e giornaliere, il server verifica i replay prima di salvare i risultati:
**la connessione può aspettare, i riflessi no.**
